Buffer overflows: quick mental model

Think of the stack as a sequence of bytes that grows and shrinks as functions call each other. Local buffers sit next to saved state (like saved base pointer and the return address).

If an input function writes more bytes than the buffer can hold, the extra bytes overwrite whatever is next. The classic target is the saved return address: overwrite it, and control the next instruction pointer.

Tip: If you can control RIP but gadgets are limited, add one extra ret for stack alignment on x86_64.

DDS in ROS 2: what matters

DDS is the middleware layer used by ROS 2 to move messages between nodes. You usually care about QoS: reliability, durability, history depth, and deadlines.

When networking is flaky, reliable + small queues can stall. For high-rate sensor streams, best-effort can be smoother. Tune QoS per topic, not globally.
